# BTC Pi Cycle Dashboard

一个轻量的 BTC 长期周期追踪看板，聚焦 Pi Cycle Top、长期均线、资金费率和持仓量。

## 使用方式

打开 GitHub Pages 页面即可实时读取 Binance 公共数据：

https://amberqian.github.io/btc-pi-cycle-dashboard/

## 指标

- Pi Cycle Top: `111DMA / (2 x 350DMA)`
- 长期趋势: 200 日均线、200 周均线
- 衍生品热度: BTCUSDT 资金费率、未平仓量
- 链上复核清单: MVRV、NUPL、Puell Multiple、RHODL、SOPR

## 风险提示

该看板用于周期风险观察，不构成投资建议。Pi Cycle 和链上指标适合看大周期风险，不适合单独作为短线交易信号。
